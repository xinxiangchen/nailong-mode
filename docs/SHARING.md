## 一段首发文案

我做了一个摄像头小游戏，叫「奶龙上身」。

你托腮，它跟着想；你捧腹，它跟着笑。转头、抬手、张手握拳，也会带动这只 3D 奶龙。一局 30 秒，90 分以上保持 2 秒，就能触发完美模仿。

思考、捧腹、仰天大笑，三种挑战都能玩。视频在浏览器本地处理，不上传；没有摄像头，也可以先看内置演示。

项目已经开源，想试的话可以从 GitHub 下载。你觉得自己最擅长哪一款？

https://github.com/xinxiangchen/nailong-mode

## 一条短视频的拍法

| 时间 | 画面 | 可配字幕 |
| --- | --- | --- |
| 0—3 秒 | 先放你与奶龙同步大笑的画面 | 我把奶龙做成了摄像头游戏 |
| 3—10 秒 | 真人和游戏画面并排，依次做托腮、捧腹、抱头 | 你做表情，它跟着动 |
| 10—18 秒 | 展示分数与完美模仿彩蛋，留下一个真实失误 | 90 分以上保持 2 秒，你能做到吗？ |
| 18—25 秒 | 回到最好笑的一幕，再给项目名和地址 | 奶龙上身 · 已开源，来试一把 |

真人录屏请自行拍摄；仓库动图是自动演示，发布时可以直接标注「内置演示」。
